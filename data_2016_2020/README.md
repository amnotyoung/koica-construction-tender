## 연도 처리 원칙

2016~2020과 2021~2025는 다운로드 작업의 범위일 뿐 분석 집단이 아니다.
각 사례는 공고일을 보존하고 연도를 연속적으로 처리한다.

- 원단가와 가격 기준일을 함께 보존한다.
- 2016년과 2020년을 같은 가격 수준으로 간주하지 않는다.
- 2020년과 2021년 사이에 인위적인 단절을 두지 않는다.
- 서로 다른 연도 단가를 합산·평균하기 전에 국가별 건설물가지수 또는
  검증 가능한 대체지수로 동일 기준일 가격으로 환산한다.
- 적절한 물가지수가 없는 사례는 명목단가로 표시하되 통계 요약에서 제외한다.
- 시간 경과에 따른 자료 관련성은 연속적인 경과연수 또는 감쇠가중치로
  표현하며, 5년 단위 더미 변수로 대체하지 않는다.

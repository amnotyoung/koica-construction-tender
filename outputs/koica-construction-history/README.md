# KOICA 과거 건축사업 조사 참고자료

## 범위

- 검색기간: 2021-01-01 ~ 2025-12-31
- 현지입찰 목록: 436건
- 건축 관련 후보: 240건
- 다운로드 첨부파일: 707개, 실패 0건
- ZIP 내부 문서 포함 분석 파일: 2,034개(숨김파일 제외 Excel 인덱스 2,028개)
- 자동 추출 수치 근거: 2,800건
- 검토 선별 공사비 단가: 48건
  - A등급 27건, B등급 12건, C등급 9건
  - 국가 요약 통계 반영: 38건
- 설계·감리 비용 사례: 7건

## 핵심 산출물

`KOICA_건축사업_과거단가_참고자료_2021-2025.xlsx`

주요 시트:

- `요약`: 국가별 명목 USD/㎡ 요약과 해석 주의사항
- `단가 벤치마크`: 연면적·공사비·USD/㎡·A/B/C 근거등급·요약포함 여부·원문 근거
- `설계감리 벤치마크`: 설계비·감리비·비율·USD/㎡
- `공고별 사업`: 건축 후보 240건의 사업·입찰 메타데이터
- `수치 근거`: 자동 추출된 2,800건의 원문 문맥과 위치
- `첨부파일`: 707개 파일의 크기·SHA-256·로컬 경로
- `파일 인덱스`: ZIP 내부 파일을 포함한 분석 대상
- `조사 체크리스트`: 제공된 심층기획조사 양식에 맞춘 확인항목

## 사용 시 주의

선별 단가는 계약 준공 실적만을 뜻하지 않는다. 공사 공고 상세페이지의
집행한도금액, 기획·설계 단계 추정예산, 직접 적용단가가 함께 포함되어 있다.
동일 공고에서 연면적과 비용을 확인한 사례는 A, 면적 합산·동일 사업의 다른
단계 문서를 연결했거나 특수시설인 사례는 B, 개보수·토목·외부공사 등
비용범위 차이가 큰 사례는 C로 분류했다. C등급 및 중복 단계 사례는
`요약포함=아니오`로 두어 국가 평균에서 제외했다.

VAT·관세·장비·외부공사·발전기 등의 포함범위와 기준연도도 서로 다르므로,
미래 사업 조사에 적용할 때는 반드시 면적 근거파일과 비용근거URL을
재확인하고 물가·환율·지역조건을 별도로 보정해야 한다.

`수치 근거` 시트는 탐색용 자동 추출 결과다. 계약실적 요건, 예시 양식,
신문 지면 등에서 나온 숫자도 포함될 수 있으므로 선별 단가와 동일한
신뢰도로 해석하면 안 된다.

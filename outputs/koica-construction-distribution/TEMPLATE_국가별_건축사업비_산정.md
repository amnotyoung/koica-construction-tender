# 국가별 KOICA 건축사업비 산정 템플릿

> 이 템플릿은 국가·시설·가격기준일이 바뀌어도 같은 통제절차를 적용하기
> 위한 작업지다. `<입력>`을 실제 조사값으로 교체하고, 확인되지 않은 값은
> 추정하지 말고 `미확인`으로 남긴다. 과거 KOICA 공고단가는 미래 사업
> 권고단가가 아니며 현지 QS·BOQ·복수 견적의 교차검증 자료로만 사용한다.

## 3. 유사사례 검색

```sql
WITH params(country_name, facility_keyword, work_name, target_area_m2) AS (
  VALUES ('<Country>', '<시설 키워드>', '<사업유형>', <연면적>)
)
SELECT
  r.bid_no, r.notice_date, r.country, r.facility_type, r.work_type,
  r.gross_floor_area_m2,
  ROUND(r.gross_floor_area_m2 / p.target_area_m2, 2) AS size_ratio,
  r.unit_usd_m2_nominal, r.evidence_grade, r.cost_stage,
  r.scope_caution, r.source_file, r.source_locator, r.source_url
FROM reviewed_cases r
CROSS JOIN params p
WHERE r.country = p.country_name
ORDER BY
  CASE WHEN r.facility_type LIKE '%' || p.facility_keyword || '%' THEN 0 ELSE 1 END,
  CASE WHEN r.work_type = p.work_name THEN 0 ELSE 1 END,
  ABS(r.gross_floor_area_m2 - p.target_area_m2),
  r.notice_date DESC;
```

동일 국가 사례가 없으면 인접 국가 평균을 자동 대체하지 않는다. 기후,
내진, 물류, 시장규모, 인건비, 수입재 비중이 유사한 사례를 별도 선별하고
`타 국가 참고사례`로 명시한다.

### 6.1 선택 우선순위

### 6.3 보정 중단조건

- 공고기간 또는 기준기간의 실제 관측값이 없다.
- 건축·토목, 지역 또는 시설범위가 대상사업과 현저히 다르다.
- USD 표시금액의 현지통화·수입재 구성과 당시 환율이 확인되지 않는다.
- 지수의 기준개편·연결계수가 확인되지 않는다.
- 전망값과 실제값을 분리할 수 없다.

중단조건에 해당하면 관측 가능한 기간까지만 계산하거나 `미보정`으로 남긴다.

## 11. 대표 유즈 케이스

| 상황 | 처리 |
|---|---|
| 동일 국가 유사사례와 공식 건설지수 있음 | 현지 견적을 주자료로 하고 범위·가격시점이 맞는 사례만 교차검증 |
| 동일 국가 사례는 있으나 건설지수가 없음 | BOQ 가중합 또는 하위 지수 사용; 불가능하면 명목사례로만 제시 |
| 동일 국가 유사사례가 없음 | 타 국가 사례는 설계·공종 참고에 한정하고 대상국 현지 견적을 주자료로 사용 |
| 수입재 비중이 큼 | 현지비·수입비를 통화와 공급국별로 분리 |
| 기준일까지 지수가 미공개 | 최신 관측종료일을 표시하고 미관측구간은 별도 시나리오 |
| 재난·급격한 인플레이션·환율변동 | 짧은 유효기간의 복수견적과 조달시점 시나리오를 우선 |
| 개보수·증축 | 기존시설 조사, 철거·임시시설·운영중 공사비를 신축단가와 분리 |
| 다수 지역·다수 동 | 지역·동별 BOQ를 분리하고 단순 합산 평균단가의 왜곡을 점검 |

## 12. 보고서 문구 골격

> `<국가>`의 `<시설>` 사업비는 `<기준일>` 기준 현지 QS·시공사 견적
> `<건수>`건을 주자료로 산정하였다. 과거 KOICA 사례 `<건수>`건은
> `<규모·범위·가격단계>` 차이를 확인한 후 방향성 교차검증에만 사용하였다.
> 가격시점 검토에는 `<지수명>`을 사용했으며 실제 관측은 `<종료기간>`까지
> 확인됐다. `<통화구성·환율·수입재 비중>`이 `<확인/미확인>`되어
> `<보정 결과 또는 미실시 사유>`로 처리하였다. 기준 시나리오의
> `<세금 포함 여부>` 총액은 `<금액>`이며, 주요 위험을 함께 변화한
> 시나리오 범위는 `<낮음~높음>`이다.

## 13. 완료 전 검사

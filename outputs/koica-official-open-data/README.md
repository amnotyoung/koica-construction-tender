# KOICA 공식 공개데이터 확장

KOICA 전자조달 현지입찰 자료만으로는 보이지 않던 발주계획, 국내
원조조달 계약, 국별사업 보고서 연결정보를 보완한 자료다. 외부 공여기관
자료는 포함하지 않았다.

## 공식 출처와 수집 범위

| 자료 | 기준판 | 행 | 공식 페이지 |
|---|---:|---:|---|
| 대외무상원조사업 연간발주계획 | 2025-12-10 | 366 | [공공데이터포털 15085055](https://www.data.go.kr/data/15085055/fileData.do) |
| 원조조달사업 계약목록 | 2026-06-30 | 115 | [공공데이터포털 15073135](https://www.data.go.kr/data/15073135/fileData.do) |
| 국별사업 보고서 목록 | 2026-07-07 | 673 | [공공데이터포털 15052832](https://www.data.go.kr/data/15052832/fileData.do) |

각 페이지에서 현재 CSV의 `contentUrl`을 동적으로 확인해 내려받는다.
직접 다운로드 URL, 원본 SHA-256, 인코딩, 행 수는
`data/manifests/koica_official_open_data.json`에 기록한다. 원본은
`data/koica_official/raw/`에 보존되며 저장소의 기존 정책에 따라 Git에서는
제외된다.

## 산출물

- `KOICA_연간발주계획_정규화.csv`: 계획 입찰한도액, 범위, 발주시기,
  사업번호 연결 결과
- `KOICA_원조조달계약_정규화.csv`: 계약번호·차수, 계약금액,
  예정가격, 변경 여부, 사업번호 연결 결과
- `KOICA_국별사업보고서_정규화.csv`: 공식 사업번호 673건과
  사업개요서 링크
- `KOICA_공식데이터_건축관련후보.csv`: 위 세 자료에서 선별한
  건축 관련 문서추적 후보 127건

재수집:

```bash
python3 scripts/fetch_koica_official_open_data.py
```

이미 받은 원본만으로 정규화 산출물을 다시 만들 때:

```bash
python3 scripts/fetch_koica_official_open_data.py --offline
```

## 이번 확장에서 바로 얻은 것

연간발주계획 366건 중 건축 관련 후보는 91건이다. 그중 입찰구분이
`공사`이고 입찰한도액과 단일 연면적을 함께 확인할 수 있는 6건은 다음과
같다.

| 사업번호 | 국가·사업 | 입찰한도액(원) | 연면적(㎡) | 원시 한도액/㎡(원) |
|---|---|---:|---:|---:|
| 2021-00156 | 인도네시아 보고르대 농업생명과학연구센터 | 3,135,564,900 | 2,281.2 | 1,374,524 |
| 2020-00119 | 이라크 한·이라크 심장병 어린이 전문병원 | 17,940,000,000 | 5,486 | 3,270,142 |
| 2021-00016 | 가나대 연구·ICT 혁신센터 | 5,382,000,000 | 2,600 | 2,070,000 |
| 2021-00009 | 인도네시아 통합지식교육센터 | 6,776,000,000 | 7,687 | 881,488 |
| 2023-00030 | 키르기스스탄 가축개량 연수센터 | 3,200,772,000 | 1,825 | 1,753,848 |
| 2022-00027 | 캄보디아 국립소아병원 내과계 병동 | 10,800,000,000 | 8,880 | 1,216,216 |

이 중 `2021-00156`, `2021-00009`, `2023-00030`은 현재 기준 SQLite의
검토완료 단가사례에 포함되지 않은 사업번호다. 따라서 기존 첨부의 BOQ와
공사범위를 재검토할 우선 후보로 쓸 수 있다.

이 값들은 2025년 발주계획의 **입찰한도액 ÷ 연면적**일 뿐이다. 실제
계약가나 준공가는 아니며, 세금·부대공사·기자재·외부공사 포함범위,
발주 이후 변경, 환율과 가격시점이 아직 보정되지 않았다. 현재 단계에서는
견적 범위 점검과 이상치 탐색에만 사용한다.

추적 키가 확보됐다.

## 조인 원칙

국별사업 보고서의 사업번호 673건은 원문 직접값이다. 연간발주계획 152건,
계약목록 50건은 국가를 제한한 뒤 공식 사업명 포함관계 또는 보수적인
문자열 유사도로 사업번호를 연결했다. 이 중 기존 SQLite와 사업번호가
일치하는 행은 각각 88건, 29건이다.

제목으로 추론한 값은 `project_link_method`와 `project_link_score`로
직접값과 구분한다. 세 공식 파일에는 현지입찰 공고번호
`LYYYY-NNNNN-차수`가 없으므로 공고번호를 만들어내지 않았다.
`existing_db_project_bid_nos`는 연결된 사업번호에 속한 기존 공고를
세미콜론으로 나열한 보조 필드이며, 해당 계획·계약과 개별 공고가
일대일로 같다는 뜻은 아니다.
